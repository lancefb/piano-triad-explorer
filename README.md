# Piano Learning Tools

Interactive web-based tools to help learn piano at any age. Features chord visualization, inversion exploration, and practice utilities.

## Features

- Octave-labeled virtual keyboard
- Triad inversion explorer (root, first, second)
- Visual chord highlighting
- Interactive practice interface

## Usage

Open `index.html` in a web browser to use the tools.

## About

Part of the "Learning to Play Piano at 70" project - using AI and interactive tools to accelerate music learning for older learners.
